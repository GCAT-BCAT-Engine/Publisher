# Temporal Governed Analysis — Publisher Projection

This document is a human-readable projection of the canonical TGA capability and its validated Site surface. It is not an independent interpretation authority.

## What TGA preserves

TGA evaluates a represented event against an explicitly identified rule, law, policy, standard, or constraint context while retaining exact temporal source references, observation encoding, rule/version context, uncertainty, provenance, and whether an evaluation is contemporaneous or counterfactual.

**Canonical representation is not canonical reality.** A compact encoding can make evidence easier to compare and reconstruct without proving that the encoding is correct.

## Current validated projection

The validated Site `Re-examine` surface can bind a user-local video to an exact temporal window and display source/time, governing context, evaluation, uncertainty, observations, provenance, and the raw TGA projection record separately. Local media availability does not establish media custody.

## Authority boundary

This Publisher projection does not create publication authority, legal conclusions, officiating decisions, enforcement authority, media custody, adjudicative authority, activation authority, or release authority. Counterfactual application is explicitly marked and does not rewrite historical applicability. Unresolved or contradictory evidence remains unresolved or contradictory.
